## 오늘 진행한 작업 요약

### 1. 카카오 로그인 KOE101 디버깅 및 수정
- 원인 1: 토큰 교환 요청에 `client_secret` 누락 (카카오 콘솔에서 Client Secret 활성화 상태였음) → `apps/api/src/api/auth/providers/kakao.ts`에 추가.
- 원인 2: 카카오 콘솔에 등록된 리다이렉트 URI가 `/api/auth/kakao/callback`(POST 전용 백엔드 API)을 직접 가리키고 있어서, 카카오가 브라우저를 리다이렉트해도 실제 처리 페이지로 연결이 안 됐음 → `/login/kakao/callback`(Next.js 페이지)으로 정정, 카카오 콘솔/env 모두 수정.
- 원인 3: `apps/web`, `apps/api`에 `.env`/`.env.local` 자체가 없어서 `client_id`/`redirect_uri`가 런타임에 빈 값이었음 → 파일 생성.
- 이후 데스크톱 브라우저로 카카오 로그인 → 온보딩 → 마이페이지(닉네임 "희재" 표시)까지 전체 플로우 검증 완료.

### 2. 마이페이지 인증 가드 추가
- `apps/web/app/mypage/layout.tsx`에 인증 체크 없어서 비로그인 사용자가 API 401 에러를 그대로 맞닥뜨리던 문제 → `authApi.me()` 체크 후 401이면 `/login`으로 리다이렉트하도록 수정.

### 3. 뉴스 크롤링 파이프라인 확장 및 검증
- 기존 연합뉴스 RSS 하나뿐이던 것을 12개로 확장 (claude.md 10.5 참고).
- 언론사별 봇 차단 방식이 반대인 문제(User-Agent 있어야 통과 vs 없어야 통과) → 없이 먼저 시도, 실패 시 User-Agent 붙여 재시도하는 폴백으로 해결.
- 국민일보 EUC-KR 인코딩 문제 → `iconv-lite`로 프롤로그 encoding 감지 후 변환.
- 중복 제거(dedupHash 기반) 정상 동작 확인 (재실행 시 이미 수집된 기사는 스킵).

### 4. DB 마이그레이션
- Neon Postgres에 마이그레이션이 한 번도 실행된 적 없었음 → `prisma migrate dev --name init`으로 초기 스키마 생성.
- 이 과정에서 `DIRECT_URL` env 변수가 없어서 실패 → `DATABASE_URL`과 동일 값(이미 unpooled 연결이라)으로 추가.

### 5. 키워드 매칭 → 알림 생성 end-to-end 테스트

- 이후 "이재명" 키워드도 최신 기사 기준으로 추가 등록.

### 6. Firebase 설정 이슈 반복 수정

### 7. 클라이언트 푸시(FCM) 연동 구현
- `apps/web/lib/firebase.ts` (클라이언트 앱 초기화), `apps/web/lib/push.ts` (권한 요청 → SW 등록 → 토큰 발급), `apps/web/public/firebase-messaging-sw.js` (백그라운드 수신), 마이페이지 프로필 화면에 "이 기기에서 받기" 버튼 추가.
- `firebase/messaging`의 `isSupported()`가 iOS Safari를 오탐하는 문제 발견 → 제거하고 `Notification`/`serviceWorker`/`PushManager` 직접 체크로 대체.
- iOS non-standalone 체크 순서가 잘못되어 있어서(브라우저 API 존재 체크가 먼저라 항상 "지원 안 함"으로 떨어짐) 순서 수정.
- **그래도 여전히 안 됐던 진짜 이유**: LAN IP 접속(HTTP)이라 iOS가 애초에 보안 컨텍스트로 인정하지 않음 (위 TODO 1번).
